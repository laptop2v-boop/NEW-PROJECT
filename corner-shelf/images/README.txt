PRODUCT PHOTOGRAPHS
-------------------
Put product photos in  images/products/  (see images/products/README.txt for the exact
file names) and list them in js/data.js:

  images: [
    "images/products/nfc-keyring-1.jpg",
    "images/products/nfc-keyring-2.jpg",
    "images/products/nfc-keyring-3.jpg"
  ]

* The FIRST photo is the one shown on cards and as the cover in the gallery.
* Use as many photos per product as you have. One photo is fine; the gallery
  arrows and thumbnails only appear when there are two or more.
* Each product has its own list. Never share one product's photos with another.
* A path starting with "/" also works ("/images/products/x.jpg").
* If a listed file does not exist yet, a neat placeholder shows instead.
* Tip: same light, same backdrop and same distance across a product's photos.
  Portrait (4:5) crops work best on the cards; the gallery crops the same way.
* Keep file sizes sensible (under about 300 KB each, 1200 px on the long side)
  so the shop loads quickly on phones.
